# Türkiye idari adres kataloğu
Kaynak: https://github.com/ubeydeozdmr/turkiye-api ve https://api.turkiyeapi.dev/v2/datasets/2025/
İndirme: 2026-10-15. Veri sürümü 2025. MIT lisansı LICENSE dosyasında korunur.
Yalnız id, name, provinceId, districtId alanları alınmıştır. 81 il, 973 ilçe, 32254 mahalle, 18183 köy.
Bağımsız veri projesidir; resmî kurum hizmeti değildir. Güncellik garantisi yoktur. TKGM kimlikleri veya parsel sınırı içermez.
tr-province / tr-district / tr-neighborhood / tr-village önekleri kimlik alanlarını ayırır; TKGM sorgusuna doğrudan verilmez.
Dosyalar sunucuda okunur, istemciye yalnız seçilen seviyenin seçenekleri gönderilir. Uygulama dağıtımında data klasörü korunmalıdır.
